# Memo — 提醒事项管理 CLI

通过 `memo` 命令行工具管理提醒事项。支持一次性提醒和周期性循环提醒。

## 前置检查

每次执行 memo 操作之前，先确认 CLI 可用：

```bash
command -v memo
```

如果命令不存在，告诉用户：

> `memo` CLI 尚未安装。请克隆 cc-skills 仓库后运行 `./install.sh memo` 进行安装。

不要继续执行后续的 memo 命令，等用户安装好后再继续。

## 核心概念

memo 有两种提醒类型：
- **一次性提醒**：绑定到某个具体日期（如"6月15日提醒我交报告"）
- **循环提醒**：按周期重复（每天/每周/每月/每年）

每条提醒有一个全局唯一的数字 ID，用于后续的完成、修改、删除操作。

## 日期处理

CLI 只接受 `YYYY-MM-DD` 格式的日期。你需要把用户的自然语言日期转换成这个格式：

- "今天" → 当前日期（运行 `date +%Y-%m-%d` 获取）
- "明天" → 当前日期 + 1 天
- "下周五" → 计算对应日期
- "6月15号" → 当年的 2026-06-15（根据当前年份推断）
- "后天" → 当前日期 + 2 天

**星期映射**：CLI 中 1=周一, 2=周二, 3=周三, 4=周四, 5=周五, 6=周六, 7=周日。

用 macOS 的 `date` 命令做日期计算：
```bash
# 明天
date -v+1d +%Y-%m-%d
# 后天
date -v+2d +%Y-%m-%d
# 下周五（先算出今天星期几，再算差值）
```

## 命令速查

### 查看提醒
```bash
memo                    # 查看今天的提醒（最常用）
memo list 2026-06-05    # 查看指定日期
```

### 添加一次性提醒
```bash
memo add "提醒内容"                      # 添加到今天
memo add "提醒内容" -d 2026-06-15        # 添加到指定日期
```

### 添加循环提醒
```bash
memo add "提醒内容" --daily              # 每天
memo add "提醒内容" --weekly 5           # 每周五（1=周一..7=周日）
memo add "提醒内容" --weekly 1,3,5       # 每周一、三、五（逗号分隔多天）
memo add "提醒内容" --monthly 1          # 每月1号
memo add "提醒内容" --monthly 1,15       # 每月1号和15号
memo add "提醒内容" --yearly 12-25       # 每年12月25日（MM-DD格式）
```

### 管理提醒
```bash
memo done <id>              # 标记完成（默认今天）
memo done <id> 2026-06-05   # 标记循环提醒在特定日期完成
memo undone <id>            # 取消完成
memo edit <id> "新内容"     # 修改提醒内容
memo rm <id>                # 删除提醒
memo search "关键词"        # 搜索提醒
```

## 自然语言转命令示例

这些是最常见的用户表达方式，理解它们的映射关系能帮你快速响应用户请求：

| 用户说的话 | 对应的命令 |
|---|---|
| "提醒我明天下午3点开会" | `memo add "下午3点开会" -d <明天日期>` |
| "帮我记一下后天要交报告" | `memo add "交报告" -d <后天日期>` |
| "6月20号有个牙医预约" | `memo add "牙医预约" -d 2026-06-20` |
| "每天早上提醒我吃药" | `memo add "吃药" --daily` |
| "每周一提醒我交周报" | `memo add "交周报" --weekly 1` |
| "工作日每天提醒我打卡" | `memo add "打卡" --weekly 1,2,3,4,5` |
| "每月1号提醒我还房贷" | `memo add "还房贷" --monthly 1` |
| "每月1号和15号发工资提醒我" | `memo add "发工资" --monthly 1,15` |
| "每年3月14日是她的生日" | `memo add "她的生日" --yearly 03-14` |
| "帮我看看今天有什么事" | `memo` |
| "把第3个提醒标记完成" | `memo done 3` |
| "删掉吃药那个提醒" | 先 `memo search "吃药"` 找到 ID，再 `memo rm <id>` |

## 工作流

### 添加提醒时

1. 从用户的自然语言中提取**提醒内容**和**时间信息**
2. 确定是一次性还是循环提醒
3. 如果是一次性，计算出 YYYY-MM-DD 格式的日期
4. 如果是循环，确定频率和对应的星期/日期参数
5. 运行对应的 `memo add` 命令
6. 用中文告诉用户已添加成功

### 查找和修改时

1. 如果用户没有提供 ID，先用 `memo search` 或 `memo` 找到目标提醒的 ID
2. 用 ID 执行 `done`/`edit`/`rm` 操作
3. 告诉用户操作结果

### 用户想批量添加时

如果用户一次性给出多个提醒，逐个运行 `memo add` 命令即可。每次添加后 CLI 会返回分配的 ID，可以汇总后一次性告诉用户。

## 注意事项

- `memo add` 的文本参数如果包含空格或特殊字符，用双引号包裹
- 循环提醒的 `--weekly` 参数支持多天，用逗号分隔，如 `1,3,5` 表示周一、三、五
- 循环提醒的完成状态是按日期记录的——`memo done 4` 只标记今天完成了，明天还会重新出现
- 如果操作失败（如 ID 不存在），CLI 会返回错误信息，把这个信息转达给用户
- 当用户表达模糊时（比如"帮我设个提醒"但没说内容或时间），主动询问缺少的信息，而不是猜测
